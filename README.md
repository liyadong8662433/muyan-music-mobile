## 声明

本项目是基于 **[lyswhut/lx-music-mobile](https://github.com/lyswhut/lx-music-mobile)** 的二次开发版本，**并非原创开发**。

原始项目作者：[lyswhut](https://github.com/lyswhut)

原始项目地址：<https://github.com/lyswhut/lx-music-mobile>

所有音乐播放核心功能、音源逻辑均来自落雪音乐，本项目仅在此基础上做了以下适配和定制：

- **车机横屏适配**：针对吉利星越L车机横屏场景优化 UI 布局
- **自定义主题**：拾光蔚蓝（浅色）、黑金（深色）主题
- **方向盘媒体按键**：适配车机方向盘按键控制播放
- **内置音源**：预置念心音源，自动下载激活
- **APP 定制**：更名为"沐妍MUSIC"，替换图标和启动图
- **推荐功能**：新增推荐页、每日30首、歌单等功能

## 技术栈

- React Native
- Redux
- react-native-track-player

## 支持平台

- Android 5 及以上（仅适配 arm64-v8a 架构）
